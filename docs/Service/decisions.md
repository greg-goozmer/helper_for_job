# Решения

| ID | Решение | Основание / последствия |
| --- | --- | --- |
| D-01 | КТ1 — интерактивный интерфейс без RAG | В предоставленном чек-листе рабочий RAG не требуется |
| D-02 | Структура Product / Tech / Service | Разделение продуктовых, технических и организационных документов |
| D-03 | Нативные ES-модули без framework | Достаточно для КТ1, запуск без скачивания зависимостей |
| D-04 | Локальная проверка по словам с явной пометкой | Позволяет пройти сценарий; не выдаётся за AI |
| D-05 | Training отделён от assessment | Требование презентации: практика не повышает readiness напрямую |
| D-06 | 3 профессии, по 3 вопроса | Минимальная демонстрация расширяемости |
| D-07 | Грейд пока только цель | Вопросы не калиброваны, ограничение видно пользователю |
| D-08 | Профиль и отчёты локально, без ответов | Достаточно для истории на КТ1 и снижает объём хранения |
| D-09 | BM25 baseline на следующем этапе | Простой измеримый retrieval до усложнения поиска |
| D-10 | Роли: Алексей — продукт/фронт; Артур — интеграция; Умиджон — RAG | Зоны ответственности закреплены за участниками команды |
