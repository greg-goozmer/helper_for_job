# План проверок

## Автоматически

`npm run check` — синтаксис JavaScript и сервера.
`npm test` — оценивание пустого/полного ответа, составные критерии, неизменяемый снимок цели, лимит истории, повреждённое хранилище, ошибка записи, покрытие навыков.

`npm run check:docs` — целостность локальных ссылок Markdown и путей манифеста. В GitHub Actions запускаются эти проверки и синтаксис (Node.js 22).

Эти тесты не проверяют реальную оценку собеседований и качество RAG.

## Браузер

1. Пройти GWT-01…GWT-16 из Product.
2. Убедиться, что в оценке не показаны рубрики, а в тренировке доступны.
3. Проверить валидацию пустого ответа и возврат к предыдущему вопросу.
4. Подтвердить, что training не меняет историю.
5. Пройти оценку, обновить страницу, проверить отчёт без ответов в localStorage.
6. Проверить смену цели, историю двух целей, пустые состояния.
7. Ширины 1440, 390 и 360 px; отсутствие горизонтального overflow страницы.
8. Клавиатура: Tab, видимый фокус, радио/чекбоксы, раскрытие details.

Результаты и фактический объём проверок: [Service/verification](../Service/verification.md). Неотмеченная проверка не считается пройденной.
