# Правила и смысл данных

## RULE-01. Цель и самооценка

Профессия и грейд задают цель подготовки. Знакомые навыки — утверждение пользователя, не подтверждённая компетентность. На КТ1 грейд не меняет вопросы; это явно указано в форме.

## RULE-02. Демо-разбор

Каждый вопрос содержит 4 критерия с вариантами ключевых слов. Ответ приводится к нижнему регистру, «ё» заменяется на «е». Критерий найден, если есть хотя бы одно слово из terms; при наличии all нужно также одно слово из этой дополнительной группы.

Процент вопроса = округление(найденные критерии / все критерии × 100).
Итог = округление(среднее процентов вопросов).

Подстрока может совпасть случайно; отрицание не распознаётся. Перечисление терминов может дать 100%. Это известное ограничение демонстрации.

## RULE-03. Training и assessment

Тренировка показывает критерии и разбор каждого ответа. Не пишет в историю и не меняет readiness. Оценка показывает критерии только после завершения; каждый завершённый проход создаёт отдельный результат. Возврат к предыдущему вопросу до завершения разрешён.

## RULE-04. Сопоставимость

Профессия, грейд и версия вопросов должны совпадать. Разница — процентные пункты, не проценты роста. Набор вопросов повторяется, поэтому улучшение результата может объясняться запоминанием. В КТ1 не вычисляется достоверный readiness.

## RULE-05. План

Для текущей цели используется последняя оценка, темы сортируются по возрастанию процента. При равенстве сохраняется порядок вопросов. Если оценки нет, показывается стартовый план. Неоценённым навыкам не присваивается нулевой уровень.

## RULE-06. Смежные роли

Покрытие = округление(число отмеченных навыков из списка смежной роли / длина списка × 100). Список отсутствующих навыков показан явно. Это маленькая иллюстративная матрица, не реальный competency graph и не прогноз трудоустройства.

## RULE-07. Хранение

localStorage с ключом interview-assistant:v1: профиль и 10 последних результатов. Результат включает снимок цели, проценты и найденные критерии; текста ответа нет. При повреждении состояние сбрасывается к безопасному начальному. При очистке истории профиль сохраняется.

## Будущие правила

Readiness будет версионироваться вместе с матрицей навыков, рубрикой и набором заданий. Training не меняет его напрямую. Для подтверждения роста нужны новые сопоставимые задания и проверка экспертом качества AI-оценки.
