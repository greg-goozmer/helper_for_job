# Интерфейс и поведение

Основа: [предоставленные макеты](../assets/interface-mockups.png). Реализация упрощена: нет персонажа, авторизации и сервера; сохранены маршрут, фиолетовые акценты, карточки и боковая навигация.

| Маршрут | Экран | Действие |
| --- | --- | --- |
| #home | Главная | Начать подготовку / попробовать демо |
| #profile | Цель и знакомые навыки | Выбор профессии, грейда, чекбоксов → компетенции |
| #competencies | Карта навыков | Изменить цель / выбрать формат |
| #modes | Два формата | Начать тренировку / оценку |
| #training | Тренировка | Критерии, ответ, разбор, повтор, следующий вопрос |
| #assessment | Оценка | Ответ, назад, далее, завершить; критерии скрыты |
| #results | Итог | Разбор по компетенциям, план, история |
| #related | Смежные профессии | Покрытие знакомых навыков, раскрытие пробелов |
| #plan | План развития | Практика по теме, новая оценка |
| #progress | История | Открыть разбор, очистить с подтверждением |

## Состояния

- Результатов ещё нет → объяснение и кнопка первой оценки.
- Ответ короче 10 символов → inline-ошибка, фокус в поле, переход заблокирован.
- Ответ до 5000 символов → счётчик; ввод сверх лимита ограничен браузером.
- Цель изменена → незавершённая сессия сброшена, история остаётся с исходной целью.
- Перезагрузка в середине сессии → предложение начать заново; ответы не восстанавливаются.
- Ошибка localStorage → предупреждение, работа в памяти.
- Неизвестный маршрут → главная.
- Внешнего loading/error AI пока нет, поскольку запросы не выполняются.

## Доступность и адаптивность

Семантические header/nav/main, ссылка пропуска навигации, подписанные radio/checkbox/textarea, fieldset/legend, aria-current, aria-invalid, aria-live для разбора. Видимый фокус; цвет дополнен текстом и символами. На узком экране карточки идут вертикально, меню разделов прокручивается отдельно. Анимации учитывают prefers-reduced-motion.

Время сессии — прошедшее время, не ограничение. Результат не скрывается за таймером.
