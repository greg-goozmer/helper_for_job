# Пользователи и сценарии

## Роли

| Роль | Задача |
| --- | --- |
| Кандидат | Выбрать цель, потренироваться, оценить ответ и увидеть план |
| Куратор корпуса (будущее) | Проверять происхождение, актуальность и качество материалов |
| Команда проекта | Проверять сценарий и метрики; не просматривать частные ответы без основания |

На КТ1 входа и серверных ролей нет. Командные обязанности перечислены в корневом README.

## Основной сценарий

Кандидат выбирает Backend/Middle, отмечает Python и SQL, открывает компетенции, проходит оценку, видит пробелы, тренируется и проходит оценку снова.

## Проверяемые сценарии Given / When / Then

| ID | Given — дано | When — действие | Then — ожидается |
| --- | --- | --- | --- |
| GWT-01 | Открыта главная | Нажать «Начать подготовку» | Открывается выбор профессии, грейда, знакомых навыков |
| GWT-02 | Выбраны профессия и грейд | Сохранить цель | Компетенции относятся к выбранной профессии; цель сохраняется после перезагрузки |
| GWT-03 | Открыта тренировка | Ввести ответ и нажать «Разобрать» | Показаны найденные и недостающие критерии; историю не меняем |
| GWT-04 | В поле только пробелы или меньше 10 символов | Отправить | Ошибка рядом с полем, вопрос не меняется |
| GWT-05 | Начата оценка | Ответить на первые два вопроса | Критерии скрыты, доступны следующий и предыдущий вопросы |
| GWT-06 | Введён третий валидный ответ | Завершить оценку | Один результат появляется в истории; доступны разбор и план |
| GWT-07 | Есть оценка текущей цели | Открыть план | Темы упорядочены от меньшего результата; кнопка ведёт в нужную тренировку |
| GWT-08 | Есть две оценки одной цели | Открыть прогресс | Видны последние проценты и разница в процентных пунктах |
| GWT-09 | В профиле отмечены навыки | Открыть смежные профессии и «Подробнее» | Покрытие и список недостающих навыков соответствуют самооценке |
| GWT-10 | Есть локальные оценки | Перезагрузить страницу | Профиль и результаты восстановлены, текстов ответов нет |
| GWT-11 | Есть история | «Очистить историю» → «Отмена» | Результаты остаются |
| GWT-12 | Есть история | Подтвердить удаление | Результаты удалены, профиль остаётся |
| GWT-13 | Ширина окна 390 px | Пройти основной маршрут | Нет горизонтальной прокрутки страницы, поля и кнопки доступны |
| GWT-14 | localStorage недоступен или повреждён | Открыть/сохранить | Сценарий работает в памяти; при ошибке записи есть предупреждение |
| GWT-15 | Нет завершённой оценки | Открыть историю или результаты | Понятное пустое состояние и действие для начала оценки |
| GWT-16 | Есть результат одной профессии | Выбрать другую цель | Компетенции и план не используют результат старой цели |
