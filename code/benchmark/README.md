# План benchmark retrieval

Статус: план, скрипта и измеренных результатов пока нет. Ответственный: Солижонов Умиджон.

1. Подготовить не менее 30 запросов по требованиям, вопросам и объяснениям разных навыков.
2. Для каждого разметить релевантные chunk_id; предусмотреть запросы без ответа.
3. Отдельно держать development и evaluation, не настраивать поиск на evaluation.
4. Сравнить BM25 baseline и последующие варианты.
5. Считать Recall@5, MRR@5, долю корректных отказов для запросов без источников и latency p50/p95.
6. Фиксировать версию корпуса, конфигурацию, seed, окружение и дату.

Recall@5 = число релевантных фрагментов в top-5 / число размеченных релевантных фрагментов.
MRR@5 = среднее 1/rank первого релевантного результата, или 0 при отсутствии в top-5.

После baseline согласовать целевые пороги. Сейчас численные показатели не заявляются.
