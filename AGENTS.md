# Работа с проектом

- Читайте README.md, STATUS.md и документы соответствующей части перед изменением.
- Пользовательский интерфейс и документация — на русском языке.
- На КТ1 достаточно интерактивного интерфейса. Не называйте локальные правила работающим AI или RAG.
- Требование связывайте с REQ-ID, сценарием GWT и проверкой. Изменение поведения отражайте в Product и STATUS.
- Тренировка не обновляет историю оценок. Сравнивайте оценки только для одной профессии, грейда и версии набора.
- Не добавляйте секреты, реальные ответы пользователей и node_modules в Git.
- Код фронта: code/frontend. Документы: docs/Product, docs/Tech, docs/Service.
- Перед коммитом кода выполните npm run check и npm test из code/frontend; проверьте затронутый сценарий в браузере.
- Не присваивайте участникам команды авторство коммитов без их участия.
